# Volume 5 — Vendor Portal

Status: ⬜ Not started (skeleton).

Self-service console for third-party sellers on a CommerceOS-powered marketplace (Volume 6) — a scoped subset of Merchant Admin capability, isolated per vendor.

## Planned modules/pages
- Vendor dashboard (their own sales/orders/payouts only)
- Product listings management (their SKUs within the marketplace catalog)
- Orders (fulfillment for items sold by this vendor)
- Payouts & commission statements
- Vendor profile / storefront presence within the marketplace
- Messaging (buyer-vendor communication)
- Performance/compliance scorecard (ship time, return rate — feeds marketplace ranking)

## Dependencies
Marketplace (Vol 6) for listing/commission rules, Orders (Vol 2.2/7) scoped per vendor, Finance (Vol 2.8/12) for split payouts.

## Next steps
Define the vendor onboarding/approval workflow and commission model before detailing individual pages — both are Volume 6 decisions this volume depends on.
