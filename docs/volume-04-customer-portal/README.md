# Volume 4 — Customer Portal

Status: ⬜ Not started (skeleton).

Self-service account area for end customers — separate from Merchant Admin (Vol 2) and Vendor Portal (Vol 5).

## Planned modules/pages
- Account overview / dashboard
- Order history & order detail (tracking, reorder)
- Returns & exchanges (self-service RMA initiation — ties into OMS Vol 7)
- Addresses & payment methods
- Wishlist / saved items
- Subscriptions (if store sells recurring products)
- Loyalty / rewards balance and history
- Support / help center integration
- Profile & communication preferences (consent management, ties to Customers Vol 2.4)

## Dependencies
Orders (Vol 2.2/7), Customers (Vol 2.4), Finance (Vol 2.8/12) for payment methods, CRM (Vol 10) for support ticket history.

## Next steps
Full-depth spec for Order History and Returns first — highest-traffic, highest support-deflection value.
