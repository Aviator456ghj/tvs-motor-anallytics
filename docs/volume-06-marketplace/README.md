# Volume 6 — Marketplace

Status: ⬜ Not started (skeleton).

Multi-vendor marketplace core: the rules engine and data model that let independent sellers list on a single storefront, modeled loosely on Amazon/Etsy dynamics per Volume 1's competitor research.

## Planned modules/pages
- Vendor onboarding & approval workflow
- Commission/fee structure configuration (flat, tiered, category-based)
- Unified marketplace catalog (aggregating vendor listings, dedupe/matching)
- Marketplace-wide search & ranking (relevance + vendor performance signals)
- Buyer protection / dispute resolution
- Vendor performance scorecards feeding search ranking
- Split payments/payouts orchestration (ties heavily into Finance Vol 12)

## Dependencies
Vendor Portal (Vol 5) as the vendor-facing surface, Products (Vol 2.3) for listing structure, Finance/ERP (Vol 11/12) for split settlement, CRM (Vol 10) for dispute handling.

## Next steps
Define commission model and vendor approval criteria first — both are prerequisites for Vendor Portal (Vol 5) detailed specs.
