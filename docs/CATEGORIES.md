# Category Taxonomy

The full set of categories seeded by `backend/app/seed/seed.py`. 16 main verticals, 97 subcategories.

Every subcategory slug is `{main-slug}-{sub-slug}` (e.g. `photography-wedding`) — see `CategoryOut`/`CategoryTreeOut` in `backend/app/schemas/catalog.py` for the API shape.
