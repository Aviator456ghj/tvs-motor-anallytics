# CommerceOS

CommerceOS (working name) is an AI-first commerce platform aiming to compete with and surpass Shopify, with future integration support for WooCommerce, Magento, BigCommerce, Amazon, Etsy, and more.

## Repository layout

- **`web/`** — Next.js (App Router) + TypeScript + Tailwind CSS application. Currently implements the Merchant Admin **Dashboard** screen (sidebar navigation, top bar, KPI stat cards, sales charts, orders/inventory/customer widgets, AI Business Assistant panel, marketing/store-health/top-products/quick-actions widgets).

## Running the app

```bash
cd web
npm install
npm run dev
```

Then open http://localhost:3000.
